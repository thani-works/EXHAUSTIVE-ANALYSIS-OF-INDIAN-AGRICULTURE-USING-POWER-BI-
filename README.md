

#  Super Store Product Analysis

###  Internship Project at Edunet Foundation


The main goal of the **Super Store Product Analysis** project was to create an **interactive Power BI dashboard** that visualizes sales, profit trends, and product performance across different regions and categories, aiding data-driven decision-making.

---

##  Project Overview

The project involves analyzing a retail store dataset to:

* Understand sales performance across regions and categories.
* Identify the most profitable products and customer segments.
* Visualize key metrics through interactive dashboards.
* Apply DAX formulas for calculated fields and performance measures.

---

##  Tools and Technologies

* **Power BI** – Data visualization and dashboard creation
* **Power Query** – Data cleaning and transformation
* **DAX (Data Analysis Expressions)** – Custom calculations and measures
* **Microsoft Excel / CSV Dataset** – Data source

---

##  Internship Timeline

### **Week 1: Introduction to Power BI**

* Learned Power BI fundamentals and its applications in data analysis.
* Imported and explored the dataset in Power BI.

### **Week 2: Learning Visualizations**

* Explored different types of charts (bar, line, pie, etc.) and their use cases.
* Customized chart appearance and layout for better readability.
* Practiced creating visualizations using sample datasets.

### **Week 3: Super Store Product Analysis**

* Loaded and transformed the **Super Store** dataset.
* Created multiple interactive visuals: **bar charts, line charts, pie charts, donut charts, cards, treemaps, funnel charts**.
* Used **filters and slicers** for interactive exploration.
* Conducted **sales and profit analysis**, identifying high-performing products and regions.
* Designed and presented a complete interactive **Power BI dashboard**.

### **Week 4: Dashboard Refinement and Reporting**

* Refined dashboard layout for better usability and clarity.
* Added **advanced filters and slicers** for detailed insights.
* Prepared a final report and project presentation for industry experts.
